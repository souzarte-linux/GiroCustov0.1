**Diretrizes Obrigatórias: Branches, Pull Requests e Merge**  
ATENÇÃO: Antes de iniciar qualquer implementação, verifique a Branch atualmente selecionada no Git.  
Cada tarefa que não explicitamente informada onde deverá ser desenvolvida, antes de realizar qualquer atividade, seja de análise ou execução / implementação de Código, deve OBRIGATÓRIAMENTE QUESTIONADO em qual Branch deve ser executado a solicitação.  
Nunca, de forma nenhuma, em nenhuma hipótese iniciar uma tarefa sem conferir em qual Branch deve ser trabalhada.  
Diretrizes obrigatórias:  
1. Não realize alterações diretamente na Branch main.  
2. Não faça merge com a main.  
3. Não altere ou exclua outras Branches.  
4. Preserve as funcionalidades existentes que não fazem parte desta implementação.  
5. Ao concluir, execute os testes pertinentes e verifique se o projeto compila.  
6. Apresente um relatório das alterações realizadas, dos arquivos modificados e dos testes executados.  
7. Não considere a implementação concluída se houver erros de compilação ou regressões identificadas.  
Aguarde minha aprovação antes de realizar qualquer operação de integração com a main.
